# IOHANNES | MGT4017

A streetwear website prototype for the MGT4017 Digital Business module. The site uses HTML, CSS and JavaScript, with local product artwork. Account, checkout and contact features are demonstrations only.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, `app.js`, and `assets/` to the repository root. In Settings → Pages, select Deploy from a branch, then `main` and `/(root)`. Save and use the published site link shown on that page.
